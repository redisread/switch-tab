# Switch Tab — logo exploration

Name: Switch Tab. Chrome recent-tab switcher; frequent keyboard users. Assumptions: playful, nimble, friendly, compact; no existing colour equity. Primary context: 16/32 px browser toolbar. User selects the direction.

Category references: local logo library productivity-collaboration sample (81 marks); blue/cyan and abstract geometry are common. Avoid stock opposing arrows, Chrome-style rings, literal card stacks without a second idea, and duck mascots (DuckDuckGo collision). Studied Kotlin, Patreon, Framer, Pagekit for negative-space construction, not tracing.

Word map: recent → memory/return; switch → hop/fold/alternate; light → ears/ribbon; tabs → short horizontal caps. Intersections: bent ear as a return gesture; S as sliding caps; folded ribbon as two views.

Concept longlist (clarity / distinction / simplicity / relevance / small-size, each /5):
1. Bent-ear rabbit: one ear folds back, the other stays alert; a friendly hopping-between-tabs companion. 5/4/5/4/5 SELECT.
2. Sliding S: two opposing rounded hooks create the initial through a staggered tab seam. 5/4/5/5/5 SELECT.
3. Fold pair: two broad folded ribbons curl toward each other, evoking a page turned back. 4/4/5/4/5 SELECT.
4. Returning duck: duck head doubles as a tab; reject browser-category association with DuckDuckGo. 4/1/4/4/4.
5. Boomerang bookmark: a bent bookmark returns to the starting point; too close to navigation arrows. 4/2/5/5/5.
6. Winking tab face: one eye closed while the other remembers; too generic as a friendly file. 5/2/5/4/5.
7. Memory knot: two connected loops capture recent order; too close to infinity/cloud brands. 3/2/4/4/3.
8. Tiny spring: a folded S jumps between pages; overly complex at 16px. 3/4/2/4/2.
9. Two hopping stones: offset rounded blocks indicate the previous step; insufficient ownable silhouette. 3/2/5/4/5.

Construction: 256-square canvases, filled paths only, transparent negative spaces. Rabbit uses 24-unit ear radii and a round lower head; S uses thick rounded opposing hooks with an open middle seam; fold pair uses 45-degree folds and mirrored brackets. Symbols are original explorations; no fonts embedded. Concept sheet typography is presentation labelling only, not a finished wordmark.

Checkpoint: select a direction before palette, final lockups, app icons or extension integration.
