# 验证记录与验收

## 自动化覆盖

- `npm test`：MRU 排序、当前窗口隔离、无痕排除、5 项上限、相同时间排序、循环选择和释放事件消费。
- `npm run test:browser`：在临时 Chromium 配置中加载真实扩展，通过 worker 向内容脚本注入命令，验证真实 tabs/storage API、松键切换、两标签来回切换、延迟面板、固定候选顺序、Esc、Enter 和弹窗渲染。
- `npm run check`：清单引用的文件存在、JavaScript 语法正确。

## macOS Chrome 手动验收

2026-11-14 本地验证：8 个单元/后台边界测试、11 个真实 Chromium 集成场景通过，清单与语法检查通过，安装包已生成。子代理发现的 macOS 快捷键符号解析和 iframe Enter 提交问题已修复并加入回归测试。反转当前标签排除条件的变异检查使测试失败，随后已还原源码。

通过原生 UI 自动化确认 Option+Q 能打开面板、Enter 能切换到预期标签。工具不支持单独发送修饰键释放，因此不能将这一结果视为真实松键手感验收；真实弹窗焦点路径曾失败，随后已修复，并通过后台回归测试和真实 action.openPopup 集成测试。
