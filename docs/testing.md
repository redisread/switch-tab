# 验证记录与验收

## 0.3 自动化覆盖

- `npm test`：18 项 MRU、后台会话校验、实际快捷键编码、缓存上限、URL/窗口隔离、导航失效及受限页面跳过测试。
- `npm run test:browser`：加载真实扩展，Chrome 返回的默认快捷键在 macOS 为 `⌘X`。通过命令消息注入验证 Meta 松键、循环、取消、iframe Enter 隔离、目标关闭、独立居中窗口及来源隔离，以及真实 captureVisibleTab 缩略图与横向卡片布局。
- `npm run check`：清单资源与 JavaScript 语法。
- `npm run package`：输出与清单版本一致的 ZIP。
- 浏览器截图保存在 `test-results/`，包含横向面板、弹窗和深色弹窗。

## 验证边界

0.1 曾通过原生 UI 自动化验证 Option+Q 打开面板、Enter 切换。该结果**不代表** 0.2/0.3 的 ⌘X 原生分发已经验收。

0.3 已验证 Chrome 注册 `⌘X` 和真实浏览器 Meta 释放处理，但集成测试注入命令消息，不代替实际键盘的完整快捷键分发。仍需实际键盘确认剪切冲突和“按住循环 → 松开 ⌘”手感，因此暂不自动合并。

## 手动验收

- [ ] 更新已安装扩展后，在快捷键设置中确认正向 ⌘X、反向 ⌘⇧X。
- [ ] A → B → C 后轻按回到 B，再轻按回到 C，面板不闪现。
- [ ] 按住 ⌘ 重复 X，每次仅移动一项；Shift 反向，松开确认。
- [ ] 输入框、文本选区、中文输入法、跨源 iframe、全屏页面中检查剪切冲突。
- [ ] 访问几个标签后出现真实缩略图；刚导航、从未访问或受限页面显示占位卡片。
- [ ] 地址栏、Chrome 设置页、网上应用店、PDF 使用居中入口和松开 ⌘ 确认。
- [ ] 切换应用、窗口、关闭目标时不会意外跳转。
- [ ] 浅色、深色、小窗口、高缩放、VoiceOver 下确认横向列表和选中播报。

缺少释放事件时保留面板，不以超时推断确认。缩略图只在本次浏览器会话内保存。

新增回归：独立窗口实际中心与来源窗口一致；连续命令在窗口加载期间仍推进选择；松开 X 不提交、松开修饰键提交；加载期间释放事件保留；失焦关闭且不抢回另一窗口的焦点。

0.3 本地已完成 18 项单元测试及 15 个有界面 Chromium 场景（包含真实独立窗口失焦关闭）。无界面 Chromium 会把多个原生窗口同时标记为 focused，因此默认无界面测试跳过这一项；CI 在 Xvfb 中以有界面模式运行完整场景。命令通过测试专用 worker 入口调用生产路由，释放事件通过 Chromium 键盘输入验证，仍不等同于物理快捷键分发。
