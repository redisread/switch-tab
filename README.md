# Switch Tab

<img src="design/logo/kit/masters/horizontal.svg" width="360" alt="Switch Tab 标志：跳格 S" />

一个面向 macOS Chrome 的最近标签切换扩展。按最近使用顺序，在当前窗口的标签之间快速切换。

## 安装

要求 Chrome 127 或更新版本。

1. 下载仓库，或解压发布包。
2. 打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本仓库的 **extension** 目录（发布包则选择解压目录）。
4. 已打开的普通网页会在切到前台后自动接入，无需刷新；停留片刻即可采集预览。
5. 在 `chrome://extensions/shortcuts` 检查快捷键是否成功分配；若有冲突，可自行更改。

可以将 Switch Tab 固定到工具栏。点击图标也会在当前 Chrome 窗口中央打开切换器，不再使用右上角工具栏弹窗。

从 0.1 更新后，Chrome 可能保留旧快捷键：在 `chrome://extensions/shortcuts` 将正向设置为 **⌘X**，反向设置为 **⌘⇧X**。⌘X 与系统剪切共用键位，注册成功时会占用该组合；可在这里改键或清除绑定。更新后重新加载扩展即可，普通网页在激活时自动补齐监听器。

横向卡片显示最近一次访问时的页面缩略图。新安装后请先访问几个标签；未采集、受限或刚导航的页面显示「暂无预览」。预览不是后台实时画面。采集会在短暂失败后有限重试，并在回到页面时重新尝试；尚未访问和 Chrome 内部页面仍显示占位。

## 操作

| 操作 | 效果 |
| --- | --- |
| 轻按 ⌘X | 返回上一个使用的标签 |
| 按住 ⌘，重复按 X | 在最多 5 个其他标签间循环 |
| 持续按住约 150ms | 显示居中选择面板 |
| ⌘⇧X | 反向循环 |
| 松开 ⌘ | 确认选中的标签 |
| ← / →（也支持 ↑ / ↓） | 移动选择 |
| Enter / 点击候选 | 确认 |
| Esc / 点击面板外 / 失焦 | 取消 |

循环选择时不会激活标签，也不会改变这一轮的候选顺序。不跨窗口、不恢复已关闭标签；只有一个标签时不切换。

### Chrome 的边界

- 扩展不能通过 Chrome commands 接管原生 Control+Tab。
- `chrome://`、Chrome 网上应用店、PDF 阅读器等无法注入浮层的页面，使用相对来源 Chrome 窗口居中的独立小窗口。快捷键打开后松开 ⌘ 确认；点击工具栏图标打开时用 Enter 或点击确认。
- 地址栏获得焦点时使用居中的独立小窗口。浏览器拦截事件、首次加载或焦点变化时，页面可能收不到松键事件；此时用 Enter 或点击确认。不会通过等待超时自动切换。
- 自定义快捷键不含 Command 或 Option 时使用 Enter 或点击确认。正向和反向快捷键需分别在 Chrome 设置中配置。
- 首版不支持无痕模式。排序以 Chrome 的 `lastAccessed` 为依据；浏览器恢复会话时不保证精确还原上次退出前的顺序。

面板只保留缩略图卡片，不显示关闭或快捷键设置按钮；改键请前往 `chrome://extensions/shortcuts`。独立小窗口的系统标题栏与关闭按钮无法通过 Chrome 扩展窗口 API 隐藏，位置受操作系统限制。失焦会取消，确认后回到来源窗口。若在小窗口监听器安装之前已松开 ⌘，仍需 Enter 或点击确认，不会用超时猜测松键。

## 权限与隐私

- `tabs`：读取当前窗口标签的标题、网址和最近激活时间。
- `storage`：在内存会话存储中保存候选标签 ID、会话令牌和缩略图，支持服务工作线程休眠。浏览器退出即清空。
- `scripting`：在已打开的普通网页中补齐内容脚本，修复安装/更新后无预览的问题；不刷新页面、不自动激活后台标签。
- `favicon`：使用 Chrome 本地 favicon 服务显示网站图标。
- `<all_urls>` 主机权限：Chrome 截取已访问网页的可见区域需要此权限。实现仅采集普通 HTTP/HTTPS 页面，不采集无痕、内部页面或文件。缩略图可能包含页面上的私人信息，只保存在本机临时内存中。
- 普通 HTTP/HTTPS 网页上的内容脚本：显示居中浮层、监听切换所需的按键。脚本在隔离环境中运行，不读取页面正文，不记录输入内容。

不设置账户、服务器、遥测或远程图标服务；不保存网页正文或浏览历史数据库；缩略图仅保存在会话内存中（最多 20 张、约 4MB），关闭标签或页面导航时清理，退出浏览器即清空。点击候选只激活现有标签，不重新访问或打开它的 URL。

## 开发与验证

扩展无运行时依赖，也无需构建。Node.js 22+ 用于测试和打包。

```sh
npm ci
npm run check
npm test
npx playwright install chromium
npm run test:browser
npm run test:browser:headed # 完整窗口焦点测试
npm run package
```

浏览器测试使用临时配置加载真实扩展，验证消息、标签切换和 UI；通过测试注入命令消息，**不等同于验证 macOS 原生快捷键分发**。截图输出到 `test-results/`，安装包输出到 `dist/`。

设计见 [docs/design.md](docs/design.md)，验收范围见 [docs/testing.md](docs/testing.md)。
